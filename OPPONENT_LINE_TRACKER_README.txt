Coach Lineup — Opponent Line Rotation Tracker

New Game Day feature: OPPONENT

How it works:
1. Open OPPONENT.
2. Enter the other team's jersey numbers.
3. Tap the opponent players currently on the field.
4. Every NEXT LINE records one opponent line rotation automatically.
   You can also use RECORD THIS LINE ROTATION inside the tracker.

The app tracks for each opponent:
- total line rotations appeared in
- percentage of all line rotations
- consecutive rotations
- maximum streak

Alert rule:
A warning appears only when BOTH are true:
- player is on more than 75% of recorded line rotations
- player has appeared in more than 3 consecutive line rotations

Example:
#22 — 80% / 4 STRAIGHT

The tracker is saved locally on the device for fast sideline use.
RESET TRACKER clears the opponent data.

No database migration required.
